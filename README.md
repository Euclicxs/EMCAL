# ⚡EM&CAL - Electricity & Magnetism Solver

A modern, interactive web application for solving electricity and magnetism problems with instant calculations and step-by-step explanations.

## Features

✨ **Interactive Physics Calculators**
- Ohm's Law calculator
- Coulomb's Law solver
- Magnetic force calculations
- Series and parallel resistance calculations

📐 **Comprehensive Formulas**
- All major E&M formulas with explanations
- Variable definitions and SI units
- Real-world applications

🎯 **Sample Problems**
- Worked examples with step-by-step solutions
- Multiple difficulty levels
- Instant calculation verification

📱 **Fully Responsive Design**
- Works perfectly on desktop, tablet, and mobile devices
- Optimized for all screen sizes
- Landscape and portrait support

## Tech Stack

- **HTML5** - Semantic structure
- **CSS3** - Responsive design with modern features
- **JavaScript (Vanilla)** - Interactive calculations and animations
- **SVG** - Custom icons and diagrams

## Getting Started

1. Open `lib/index.html` in your web browser
2. Navigate through the sections using the menu
3. Select a calculator or formula to explore
4. Input your values and get instant results
